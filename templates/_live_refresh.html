{# Background auto-refresh that survives bad Wi-Fi. Instead of reloading the whole page (which leaves a dead browser error page if the network blips), fetch the page quietly and swap in the new content only if it arrived. On failure the old data stays up, a small "Reconnecting" badge shows, and it retries. Options (set with {% with %} around the include): live_seconds how often to refresh (required) live_target '#live-root' (default, the page body in base.html) or 'html' (whole page, overlays) live_badge false to hide the reconnecting badge (stream overlays) live_pause_hidden false to keep refreshing while the tab is hidden (stream overlays) Countdowns: any element with class "countdown-timer" and data-ends-at (ms since epoch) ticks down every second; data-suffix is added after the time. #}
